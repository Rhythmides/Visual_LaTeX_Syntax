# Visual LaTeX Syntax

> **⚠️ 重要声明：本项目代码及本文档主要由 AI 生成，属于轻量级原型（Prototype）阶段。**
> 虽然核心功能（如基线排版、多行对齐、分段函数）已跑通，但在复杂的公式嵌套、极端排版场景下，**部分功能可能仍存在 Bug 或待完善**。请将其作为视觉辅助工具使用，并在导出后仔细核对生成的 LaTeX 源码。

Visual LaTeX Syntax 是一个以“视觉输入”为核心的轻量级桌面公式编辑器。它不是代码编辑器：用户在画布中直接操作排版后的公式，再导出兼容 Markdown 的 LaTeX 数学公式代码。

## 运行环境
Python 3.10 或更高版本。

使用系统自带的 Tkinter 图形库，无需 pip 安装任何第三方依赖。

macOS 用户注意：若提示缺少 Tkinter，需要安装带 Tk 支持的 Python 发行版（如 python.org 的官方安装包）。

Linux 用户注意：可能需要安装发行版的 python3-tk 系统包。

## 启动命令：

bash
python3 visual_latex_syntax.py

## 基本操作
输入：直接在画布中输入字母、数字和常见标点。

插入结构：点击上方“结构”标签，插入分数、根号、上下标、积分、矩阵、分段函数等。

光标移动：

← / →：在结构内部移动，到达边界时会自动跳入或跳出结构。

↑ / ↓：根据视觉位置在行与行、上下标之间跳转。

鼠标点击：精准点击画布中的占位符 □ 或字符，直接定位光标。

删除：Backspace 删除光标前的内容，若在结构最前方则跳出结构；Delete 删除光标后的内容。

换行与对齐：使用“换行 ⏎”或直接按 Enter 键换行；使用“对齐 &”插入等号对齐符。

编辑与撤销：Ctrl+Z (macOS 为 Cmd+Z) 撤销。

输出与 Markdown 兼容性
导出的公式默认使用 `$$ ... $$ `包裹。若包含换行或对齐符，会自动包裹在 `\begin{aligned} ... \end{aligned} `环境中。

---

🧪 关于化学公式（需要额外插件）
本编辑器支持通过“化学”标签插入简化的化学方程式。
请注意： 导出的化学公式使用了` \ce{...} `语法（mhchem）。这在标准的纯 Markdown 中无法直接渲染，你必须确保你的 Markdown 阅读器（如 Obsidian、Typora、VS Code 等）或其底层渲染引擎（KaTeX / MathJax）已开启并安装了 mhchem 扩展。否则将显示为源码或报错。

📝 关于 Markdown 渲染报错
如果你在本地导出后发现预览报错，请检查：

你的渲染器是否支持` \begin{aligned} `环境（如果是极简排版引擎可能不支持）。

矩阵或分段函数的嵌套是否过于复杂，部分简易引擎对` \begin{pmatrix}` 和` \begin{cases} `支持有限。

当前原型的边界与已知问题
由于是 AI 生成的轻量级原型，以下场景可能遇到 Bug：

复杂结构的鼠标命中：虽然加入了基于字体度量的命中判定，但在深度嵌套（如分数里的根号里的上下标）时，鼠标点击可能偶尔无法落入预期的空位。

排版微调：大括号（分段函数）和超大矩阵的垂直对齐依赖字体的实际渲染高度，在不同操作系统下可能有细微偏移。

多步撤销限制：撤销栈虽然实现了，但在极快速连续操作下，状态记录可能偶尔遗漏（建议输入完一段后确认再继续）。

缺少语法校验：导出的 LaTeX 代码未经过严格的语法解析器校验，完全依赖程序自身的拼接逻辑。
